## Scope: existing incident application

The roles below authorize the current incident web application. They do not
authorize generic Harness tools, and they are not required by the neutral core.
Harness execution authority comes from trusted tool registration and `Policy`;
the planned single-operator Service entry protection is a separate adapter concern.

System role and project role are separate. A system administrator can create
local users and projects; project membership controls access inside one project.

The single-user self-hosting direction does not mean authentication has been removed from the existing service.

## System role

| Role     | Current capability                                                  |
| -------- | ------------------------------------------------------------------- |
| `admin`  | Bootstrap-only privileged account; create viewer users and projects |
| `viewer` | Normal login identity; project permissions come from memberships    |

New users created through the API receive system role `viewer`. Grant project
access separately.

## Project role

| Project role | Read project/config/events/incidents/audit | Create or update incidents | Manage members/config/credentials |
| ------------ | ------------------------------------------ | -------------------------- | --------------------------------- |
| `admin`      | Yes                                        | Yes                        | Yes                               |
| `operator`   | Yes                                        | Yes                        | No                                |
| `viewer`     | Yes                                        | No                         | No                                |

A project must retain an administrator. The server returns capabilities with
project responses; clients and operators must not infer permission from a local
UI state or system role name.

## Not-found boundary

A non-member receives the same project-not-found response as an unknown project.
This is intentional protection against project-key enumeration.
