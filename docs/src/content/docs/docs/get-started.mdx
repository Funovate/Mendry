FixThe currently runs from this repository as independently buildable frontend
and backend packages. A supported customer installation artifact is not yet
released.

## Available now

- Review the source-controlled product architecture.
- Build and validate the frontend and backend in a development environment.
- Evaluate incident and remediation behavior with synthetic fixtures.

## Release gate

Production installation instructions will appear only after the installation
artifact, support policy, security boundary, and rollback process are tested.
