**Availability: preview**

The current operator journey runs FixThe from this repository. It is suitable
for evaluation and development validation, not as a supported customer
installation.

## Journey

1. Confirm the [prerequisites](/docs/get-started/prerequisites/).
2. Read the [installation status](/docs/get-started/install/) before choosing an environment.
3. Run migrations and [bootstrap the administrator](/docs/get-started/bootstrap/).
4. Create and configure the [first project](/docs/get-started/first-project/).
5. Send a supported signal and inspect the [first incident](/docs/get-started/first-incident/).

## Authority boundary

FixThe may collect evidence and prepare a diagnosis or candidate remediation.
A person still reviews the evidence and controls merge, deployment, rollback,
and recovery conclusions.
