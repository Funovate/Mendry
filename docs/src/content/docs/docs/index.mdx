**Availability: available**

This documentation separates current executable behavior from release plans.
FixThe is customer-managed incident investigation and controlled remediation
software. It collects project-owned evidence, produces reviewable diagnoses and
candidate plans, and leaves merge and deployment decisions with people.

## Choose a path

- [Get started](/docs/get-started/) with the source-based evaluation journey.
- Review [architecture](/docs/concepts/architecture/) and [security boundaries](/docs/concepts/security/).
- Configure [signed webhooks](/docs/guides/signed-webhooks/) or review [Tencent CLS](/docs/guides/tencent-cls/).
- Check [product status](/docs/project/status/) before relying on a capability.

## Documentation policy

Commands appear only when current code, tests, or a tested release artifact
supports them. The production installation page remains blocked until a customer
installation artifact and support boundary are verified.
