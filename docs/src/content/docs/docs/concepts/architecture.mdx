**Availability: available**

FixThe is one repository with independently buildable frontend, backend, and
documentation packages. The browser console calls the Go API; PostgreSQL holds
business state, while Redis holds only revocable login sessions.

## Runtime flow

1. A project administrator stores project configuration and encrypted credential references.
2. A signed webhook or authenticated connector creates a project-owned Observation.
3. Incident ingestion groups the signal by a bounded fingerprint and opens or updates an Incident.
4. The remediation coordinator reads only project/run-scoped evidence through trusted adapters.
5. A review projection presents evidence, diagnosis, and candidate plan to an operator.
6. People control merge, deployment, rollback, and recovery decisions.

## Backend boundaries

Commands construct process dependencies. HTTP adapters call application
services; application and domain packages do not import HTTP, PostgreSQL, Redis,
or provider clients. Feature packages own their SQL and adapters.

The API process runs webhook background work and remediation coordination today.
RabbitMQ, a durable general job queue, and remote telemetry export are not part
of the current runtime.
