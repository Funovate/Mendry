**Availability: planned**

FixThe does not yet publish a tested customer installation artifact. There is no
supported image, Compose manifest, package, upgrade procedure, or production
rollback procedure to document.

## Publication gate

Production installation guidance remains blocked until all of these inputs are
reviewed together:

- a tested customer installation artifact;
- explicit release and support status;
- a documented security and authority boundary;
- a verified upgrade and rollback path;
- an approved canonical documentation domain and authorized brand assets.

The source-based evaluation pages remain available as preview documentation,
but they do not establish production support.
