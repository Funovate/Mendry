**可用性：planned**

Mendry 尚未发布经过验证的客户安装制品，因此目前没有可记录为受支持流程的镜像、Compose 清单、软件包、升级步骤或生产回滚步骤。

## 发布门禁

只有以下输入一起通过审阅后，才会发布生产安装指南：

- 经过验证的客户安装制品；
- 明确的发布与支持状态；
- 已记录的安全和权限边界；
- 经过验证的升级与回滚路径；
- 已批准的文档规范域名和品牌资源。

源码仓库：[GitHub 上的 Funovate/Mendry](https://github.com/Funovate/Mendry)。
基于源码的评估页面仍可作为预览文档使用，但不会由此形成生产支持承诺。

## 下一步

如仅需评估仓库，可继续[初始化登录账号](/zh-cn/docs/get-started/bootstrap/)。
