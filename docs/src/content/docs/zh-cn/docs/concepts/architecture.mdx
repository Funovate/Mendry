**可用性：available**

FixThe 是单仓库项目，前端、后端与文档可独立构建。浏览器控制台调用 Go API；PostgreSQL 保存业务状态，Redis 只保存可撤销的登录 Session。

## 运行流程

1. 项目管理员保存项目配置和加密凭据引用。
2. 签名 Webhook 或已认证连接器创建项目内 Observation。
3. 事故摄取通过有界 fingerprint 对信号分组，并创建或更新 Incident。
4. 修复协调器只能通过可信适配器读取项目与 run 范围内的证据。
5. review projection 向操作员展示证据、诊断和候选方案。
6. 合并、部署、回滚与恢复决定由人控制。

## 后端边界

命令负责组装进程依赖。HTTP adapter 调用 application service；application 和 domain 包不导入 HTTP、PostgreSQL、Redis 或提供方 client。每个 feature 包拥有自己的 SQL 与 adapter。

当前 API 进程负责 Webhook 后台处理和修复协调。RabbitMQ、通用持久任务队列和远程 telemetry export 不属于当前运行时。
