**可用性：preview**

当前操作流程直接从本仓库运行 FixThe，适合评估和开发验证，不等同于受支持的客户安装方式。

## 操作流程

1. 确认[前提条件](/zh-cn/docs/get-started/prerequisites/)。
2. 选择环境前阅读[安装状态](/zh-cn/docs/get-started/install/)。
3. 执行迁移并[初始化管理员](/zh-cn/docs/get-started/bootstrap/)。
4. 创建并配置[首个项目](/zh-cn/docs/get-started/first-project/)。
5. 发送受支持的信号并检查[首个事故](/zh-cn/docs/get-started/first-incident/)。

## 权限边界

FixThe 可以收集证据并准备诊断或候选修复方案。证据审阅、合并、部署、回滚和恢复结论仍由人控制。
