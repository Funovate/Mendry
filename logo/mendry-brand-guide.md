# Mendry 标志使用说明

## 文件清单
- `mendry-logo-horizontal.svg` — 主版本横向组合标志（深墨绿），用于浅色背景
- `mendry-logo-horizontal-reversed.svg` — 反白版横向组合标志，用于深色背景
- `mendry-logo-mono.svg` — 单色版，用于印章、雕刻、单色印刷
- `mendry-mark.svg` — 仅图形标志（深墨绿），用于浅色背景的小尺寸场景
- `mendry-mark-reversed.svg` — 仅图形标志（反白），用于深色背景的小尺寸场景
- `mendry-icon-tile.svg` / `mendry-icon-tile-512.png` — 现成的应用图标 / favicon，512x512，圆角方形

所有 SVG 均为透明背景、矢量路径（含字体轮廓，无需安装字体即可在任何设备上正确显示），可直接在 Figma、Illustrator、Sketch 中打开编辑。

## 色彩
| 用途 | 名称 | HEX |
|---|---|---|
| 主色（图形/文字） | 墨绿 Ink | `#17281F` |
| 反白色 | 米白 Cream | `#F3F0E7` |
| 强调色（缝合点） | 琥珀 Amber | `#C1893E` |
| 深色底 | 深墨绿背景 | `#12211A` |

## 使用建议
- **最小尺寸**：图形标志不小于 24px，横向组合标志不小于 96px 宽，小于此尺寸建议只用图形标志。
- **留白空间**：标志四周至少保留与图形标志高度相当的空白区域，避免与其他元素、边缘贴得太近。
- **背景选择**：浅色/中性背景用主版本；深色背景（如产品截图里的深色终端卡片）用反白版本。
- **不要**：拉伸变形、更换琥珀色点的颜色、把图形和文字拆开单独使用又不对齐、在低对比度背景上使用单色版。
