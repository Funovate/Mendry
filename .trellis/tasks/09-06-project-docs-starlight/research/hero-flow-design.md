# Hero Right-Side Flow Proposal

## Scope

Planning-only prototype: `hero-flow-concept.html`. Supersedes the earlier
full-width proposal. The user explicitly limited the request to the existing
hero screenshot area. Preserve the existing left copy, actions, column layout,
and following page sections. Do not relocate the screenshot or add sections.
The reference website is an aesthetic benchmark, not a design template.
No production file, function, class, or method is modified.

## Composition

A compact four-stage path fits inside the right-hand figure:

1. Top left: incident signal, runtime evidence, and code context.
2. Top right: FixThe investigation with three concise actions.
3. Bottom right: diagnosis and candidate plans with evidence provenance.
4. Bottom left: human review and explicit human merge/deployment authority.

Directional connectors run right, down, and left. Numbered labels disambiguate
reading order. The shape ends at human review and never loops into automatic
production actions. It contains no synthetic metrics or fabricated diagnosis.

Reuse the current canvas and typography. White input artifacts contrast with a
charcoal investigation block, a restrained result document, and an unframed
human-review endpoint. Teal connectors, blue evidence detail, and amber human
authority provide a small functional palette. No gradient, hub/orbit layout,
third-party branding, remote assets, or JavaScript dependency.

## Prototype Boundary

The standalone mock imports current production CSS for its unchanged left side;
it is Chinese-only and omits the surrounding Starlight header. Its next-section
heading provides placement context, not a redesign. Action links target existing
local build pages. Production integration still requires approved design,
bilingual copy, theme handling, accessible diagram semantics, and package tests.

Desktop retains the current two-column hero. Mobile stacks the existing left
copy above the compact two-by-two diagram without shrinking the entire figure.
Connector animation respects reduced motion.

## Review And Validation

Review desktop, 390px, and 320px screenshots for diagram fit, line direction,
text wrapping, image-area proportions, and unchanged left content. Verify local
